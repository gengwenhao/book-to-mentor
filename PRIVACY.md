# Privacy

Book-to-Mentor is a local, skills-only project. Its bundled scripts do not send books, extracted text, learning records, or analytics to the project author.

The agent host, model provider, operating system, package installer, or optional document parser you use may process or retain data under its own terms. Review those services before using confidential, personal, or copyrighted material.

When submitting feedback, remove book text, personal notes, credentials, and private file paths unless you have explicitly chosen and are authorized to share them.

Privacy questions may be submitted through the repository's GitHub Issues page.
