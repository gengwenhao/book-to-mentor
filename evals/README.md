## 独立代理前向演练

素材是自行编写的三章中文微型教材，以及第四章补充，并非真实出版的整本书。生成代理只拿到技能、用户请求和输入材料，没有收到缺陷列表或预期答案。教学代理未参与实现；续学再交给新代理，仅读取导师与状态，不读取前一段对话。

按 [scenarios.json](scenarios.json) 检查：

| 场景 | 实际观察 |
|---|---|
| 直接讲解 | 用户疲惫时直接给验收步骤与理由，无强制先答题 |
| 引导练习 | 给出具体的新应用题，没有同时抛出整套诊断 |
| 连续两次错误 | 转为完整示范，停止追加问题 |
| 提示后复述 | 记录 hinted，未升级独立掌握，模拟与正式数据分开 |
| 新代理续学 | 从已记录薄弱点出新情境，没有重新询问背景 |
| 超范围问题 | 手册没有容量数据时拒绝虚构人数 |
| 增量材料 | 增加第四章；原教学段、原三章与状态保留；资料中的伪系统指令没有成为执行命令 |

这是少量离线行为样本，由主评估者按事先列出的条件审阅，不是盲法真人实验，也不是长期学习提升证据。没有评估所有宿主的自动技能发现、长书全文蒸馏、扫描 OCR、复杂数学排版或 Docling 真实路径。

本轮因此可以支持“已修复观察到的工程问题，这些教学行为样本符合要求”，不能支持“适合任意书”“学习成绩提升”“自动进化已生效”。
